# АптекаПоиск

Введите название лекарства — приложение откроет поиск на сайтах аптек (Аптека April, Столички, Аптека.ру, Ригла, ЕАПТЕКА, ЗдравСити).
Собственного каталога и цен нет: актуальные цены и наличие показывают сами аптеки.

Есть история запросов, избранные запросы и тёмная/светлая тема. React + TypeScript + Vite, Tailwind CSS, Zustand.

## Запуск
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # проверка типов + production-сборка
```

## Как добавить аптеку
Список сайтов и шаблоны адресов поиска — в `src/lib/pharmacySites.ts`.

## Деплой
GitHub Pages через Actions (`.github/workflows/pages.yml`) при пуше в `main`.
